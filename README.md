# EOT SERVER LIST V43 — Reliable Match Sharing Worker

Cloudflare Worker for the EXISTING `eot-preview2` deployment.
Matches game ID and public game-server address against the live Starblast feed.
Discord receives Open Graph metadata and an image; human browsers join the verified
OPEN Starblast game. No guessing, no private network fetching and no clan rankings.

Deploy to `king-community/eot-preview2` (same Worker name) and verify using `npm test`.
